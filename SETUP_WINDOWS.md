# Запуск на Windows 11

Всё, что нужно другу для запуска проекта «Грильяж».

## Быстрый старт (5 минут)

### Шаг 1. Установите Docker Desktop

1. Скачайте с https://docs.docker.com/desktop/setup/install/windows-install/
2. Установите, перезагрузите компьютер
3. Запустите Docker Desktop — дождитесь зелёного индикатора внизу слева

> Docker нужен для PostgreSQL (база данных) и Mailpit (тестовая почта).

### Шаг 2. Установите Node.js

1. Скачайте с https://nodejs.org/ (версию **22 LTS** или новее)
2. Установите, перезагружать не обязательно

### Шаг 3. Запустите проект

1. Распакуйте архив с проектом в любую папку (путь **без кириллицы и пробелов**, например `C:\Projects\Grilyage`)
2. Зайдите в папку и **дважды кликните** `start.bat`
3. Первый запуск займёт ~2 минуты (скачиваются npm-пакеты)
4. После подготовки откроется **лаунчер** — нажмите **«Быстрый старт»**
5. Лаунчер сам запустит API и Web, откроется браузер с сайтом

### Что откроется

| Адрес | Что там |
|---|---|
| http://localhost:3000 | **Сайт** — меню, корзина, оформление заказа |
| http://localhost:3000/admin | **CRM** — управление заказами, каталогом, сотрудниками |
| http://localhost:4000/api/docs | **Swagger** — документация API |
| http://localhost:8025 | **Mailpit** — тестовая почта (письма подтверждений) |

### Вход в CRM

- **Логин**: `admin`
- **Пароль**: `admin123`

### Повторный запуск

В следующий раз просто дважды кликните `start.bat` — он проверит, что всё на месте, и откроет лаунчер.

## Если что-то пошло не так

### «docker не найден»

Установите Docker Desktop (Шаг 1) и перезапустите `start.bat`.

### «npm install не удался»

- Проверьте интернет
- Откройте `cmd` в папке проекта и выполните `npm install` вручную

### Порты заняты

Другие программы могут занимать порты 3000 (Web), 4000 (API), 5432 (PostgreSQL).
Закройте программы, использующие эти порты, или нажмите в лаунчере «free 4000» / «free 3000».

### Ошибка «Cannot find module»

Попробуйте в `start.bat` режим полной переустановки:
1. Удалите папку `node_modules`
2. Удалите `package-lock.json`
3. Запустите `start.bat` заново

### Яндекс.Карты не грузятся

Получите бесплатный API-ключ в https://developer.tech.yandex.ru/ и впишите его в файл `.env`:
```
NEXT_PUBLIC_YANDEX_MAPS_API_KEY=ваш_ключ
```

## Минимальные требования

- **ОС**: Windows 11 (x64)
- **ОЗУ**: 8+ ГБ (Docker Desktop + Node.js + проект ~4 ГБ)
- **Диск**: 5+ ГБ свободного места
- **Интернет**: нужен для первого запуска (скачивание образов и пакетов)
- **Docker Desktop** с WSL2 (устанавливается автоматически)
- **Node.js** 22+

## Структура проекта

```
GrilyageV2-main/
├── start.bat          ← точка входа (дважды кликнуть)
├── .env.example       ← образец настроек
├── infra/
│   └── docker-compose.yml  ← PostgreSQL + Mailpit
├── apps/
│   ├── api/           ← NestJS API (:4000)
│   ├── web/           ← Next.js сайт (:3000)
│   └── launcher/      ← Electron лаунчер (управление сервисами)
└── package.json       ← корневой скрипт
```
