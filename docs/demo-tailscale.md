# Demo Through Tailscale

## Цель

Показать проект с другого устройства через Tailscale без публикации в интернет.

## Подготовка

1. Установить и авторизовать Tailscale на машине с проектом.
2. Запустить лаунчер: `npm run launcher`.
3. В лаунчере проверить блок `Окружение`: `Tailscale CLI` и `Tailscale IP` должны быть `OK`.
4. Нажать `Запустить все`.
5. Выполнить `migrate`, затем создать/обновить CRM аккаунт `admin / admin123` с ролью `ADMIN`.

## Адреса Для Показа

- Сайт: `http://<tailscale-ip>:3000`
- CRM: `http://<tailscale-ip>:3000/admin`
- Swagger: `http://<tailscale-ip>:4000/api/docs`
- Mailpit: `http://<tailscale-ip>:8025`

## Сценарий Демонстрации

1. Открыть сайт, показать hero, категории, поиск и корзину.
2. Добавить блюдо, оформить заказ.
3. Открыть CRM, войти как `admin / admin123`.
4. Открыть заказы и показать смену статусов.
5. Открыть Swagger для демонстрации API-контракта.

## Если Порт Занят

Если лаунчер показывает, что Web или API уже запущены, повторно запускать сервис не нужно. Освободить порт можно закрытием старого терминала или процесса, который держит `3000`/`4000`.
