## P1 — Критичные проблемы (10 задач)

*Безопасность, производительность, compliance. Требуют исправления в течение 1-2 спринтов после запуска.*

### P1-1. Nonce-based CSP (вместо `'unsafe-inline'`)

| Поле | Значение |
|------|----------|
| **Описание** | Генерация nonce для каждого запроса, внедрение в Helmet CSP, обновление Next.js для поддержки nonce. |
| **Риск** | **Высокий.** XSS-атаки могут инжектить произвольный JavaScript. CVSS 7.5. |
| **Сложность** | H |
| **Зависимости** | — |
| **Трудозатраты** | 16-24ч |
| **Команда** | Backend + Frontend (Next.js) |

### P1-2. CSRF origin-check + CSRF-токены

| Поле | Значение |
|------|----------|
| **Описание** | Добавить проверку `Origin` / `Referer` header для state-changing запросов. Добавить CSRF-токены для staff-операций. |
| **Риск** | **Высокий.** CSRF-атаки на staff-операции (смена статусов, назначение курьеров). |

| **Зависимости** | — |
| **Трудозатраты** | 6-8ч |
| **Команда** | Backend |

### P1-3. Перевести access-токены в httpOnly cookie

| Поле | Значение |
|------|----------|
| **Описание** | Перевести client access-токен из `localStorage` в httpOnly cookie (как staff). Обновить frontend (убрать `Authorization` header, полагаться на cookie). |
| **Риск** | **Высокий.** XSS → кража токенов из `localStorage` → полный доступ к аккаунту. |

## Риски roadmap'а

### Риск 1: Недостаток ресурсов

- **Описание:** Текущая команда = 1 разработчик + AI-агенты. Реальные трудозатраты в 2-3 раза выше.
- **Влияние:** Задержки в 2-3 раза. P0 может занять 12-18 недель вместо 4-6.
- **Mitigation:** Hiring plan, outsourcing критических задач (платёжный шлюз, SMS).

### Риск 2: Зависимости от внешних сервисов

- **Описание:** YooKassa, SMS.ru, Cloudflare — внешние зависимости. Изменения API, downtime.
- **Влияние:** Задержки, дополнительные трудозатраты.
- **Mitigation:** Fallback'ы, retry logic, мониторинг внешних сервисов.

### Риск 3: Техдолг накапливается быстрее, чем устраняется

- **Описание:** Новые фичи добавляют новый техдолг. Старый техдолг не устраняется.
- **Влияние:** Проект застревает в «legacy mode».
- **Mitigation:** 20% времени на техдолг каждый спринт.

### Риск 4: Soft-launch → полный запуск без устранения P1

- **Описание:** Бизнес давит на запуск, P1 откладывается.
- **Влияние:** Security incidents, performance issues, reputational damage.
- **Mitigation:** Жёсткие Go/No-Go критерии. Нет soft-launch без P0.
