Проект представляет из себя Сайт, сервис по доставке и некий crm для уже существующего гастрохауса Грильяж. Дизайн сайта расположен в папке Site в папке проекта.
Более подробно о каждом аспекте проекта
1.Сайт - В целом обычный сайт где можно посмотреть и заказать доставку или самовывоз. По функционалу должен быть как большинство сайтов фастфуда по типу kfc или mcdonalds.Должна быть регистрация и личный кабинет.Должна быть мобильная версия сайта.
Для посетителей сайт предельно ясен, а вот для персонала должен быть удобен. Должна быть система редактирования меню, добавление позиций и тд. Файловая система сайта должна уметь подгружать картинки блюд в себя, например администратор при создании блюда может загрузить имеющийся файл на устройстве.
Таким образом мы плавно подошли к некому crm - это админская\операторская часть сайта которая должна быть скрыта от пользователя и иметь другую систему аккаунтов, отдельную от обычных пользователей. В ней будет инструментарий разделенный на несколько систем, администраторский - для управлением меню, редактированием,добавлением. Возможность создания акций и тд. Второй системой будет операторская - в ней для начала будут отображаться заказы, все по классике, адрес, время, что заказали и контакная информация. По первой будет только обратная связь, но в конечном итоге планируется система чата с оператором, возможность звонков которая будет реализована с помощью webrtc и работать из фирменных приложений. Так же немаловажно поднять iredmail в  данном проекте, который будет иметь два назначения, корпоративная почта у которой будет низкая загрузка, персонала не много а из файлов там максимум таблицы с отчетами или небольшие сканы документов в формате pdf. Второе назначение это подтверждение почты при регистрации пользователя, так как вариант с смс подтверждением номера для компании пока дороговат.
Теперь про приложения. Нужны версии для android и ios. Фактически это дубликат пользовательского сайта, однако это не должно быть простым веб-приложение, нужно сделать функционал api. Приложение по стилю будет похожим на сайт, быть легкодоступным на любых экранах.
Серверная часть в продакшн версии проекта будет распологаться на арендованом vps, пока компания не сможет позволить себе самохостинг. Исходя из этого учти такую вещь что в ходе разработки, проект должен запускаться как на linux системах так и на windows. Linux систем будет две так как основной дистрибутив на пк для разработок это arch, арендованый vps на ubuntu самой свежей версии, не ниже 24.04.
Стек технологий для этого проекта не так важен, главное в конечном итоге получить работоспособность, гибкость,отказоустойчивость, легкость обновления и настройки.
