# Grilyage Platform

Проект представляет собой платформу доставки еды для гастрохауса Грильяж.

Стек:

- Next.js
- NestJS
- PostgreSQL
- Prisma
- Flutter
- Docker

Роли:

- User
- Operator
- Courier
- Admin

Общие правила:

- Не ломать обратную совместимость API.
- Не изменять бизнес-логику заказов без анализа последствий.
- Все решения должны работать на Windows и Linux.
- Целевая серверная система Ubuntu 24.04.
- Безопасность важнее скорости разработки.
- Простота поддержки важнее сложных архитектурных решений.
